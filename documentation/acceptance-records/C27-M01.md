## 1. Purpose

Look at the audit trail as an operator would. There is no administration screen for it: it is read with `wp noblen audit ...` commands, run with `--user=<login>`. Only the Publication Approver role may read it.

## 2. Prerequisites

- A staging copy of WordPress 6.4 or newer on PHP 8.3 or newer, built from the release packages (`scripts/build-packages.sh`: `noblen-corporate-theme.zip`, `noblen-corporate-core.zip`, `SHA256SUMS`), never production. WP_DEBUG and WP_DEBUG_LOG on so that PHP problems are recorded.
- Staging with a configured audit key and some publication activity (publish and revoke a record). An approver login and an editor or administrator login.
