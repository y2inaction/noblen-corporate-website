## 1. Purpose

Use the site with the keyboard only. The automated checks (C14-001 to C14-003) support this pass and are not the acceptance test; this record is.

## 2. Prerequisites

- A staging copy of WordPress 6.4 or newer on PHP 8.3 or newer, built from the release packages (`scripts/build-packages.sh`: `noblen-corporate-theme.zip`, `noblen-corporate-core.zip`, `SHA256SUMS`), never production. WP_DEBUG and WP_DEBUG_LOG on so that PHP problems are recorded.
- No mouse or touch input is used during the steps.
