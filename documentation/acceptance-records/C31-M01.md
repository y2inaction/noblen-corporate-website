## 1. Purpose

The owner checks that when a published record changes or is withdrawn, the administration tells the operator which addresses to purge from any page cache or CDN, and that after purging the public page is correct. The plugin cannot reach a cache itself; this is a procedure check.

## 2. Prerequisites

- A staging copy of WordPress 6.4 or newer on PHP 8.3 or newer, built from the release packages (`scripts/build-packages.sh`: `noblen-corporate-theme.zip`, `noblen-corporate-core.zip`, `SHA256SUMS`), never production. WP_DEBUG and WP_DEBUG_LOG on so that PHP problems are recorded.
- Any page cache or CDN the owner intends to use, or the browser cache if there is none. A published test record.
