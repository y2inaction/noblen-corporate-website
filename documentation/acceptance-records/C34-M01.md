## 1. Purpose

The owner walks through the custody of the audit key and then rehearses rotation and recovery on a disposable staging copy with throwaway keys, using the operator commands `wp noblen key ...` (see RECOVERY.md, "Audit key custody"). The repository runs the same procedure automatically on a disposable site (`tests-cli/key-custody-rehearsal.py`); that automated run proves the commands work and is NOT a substitute for this record. NEVER use the production key, or a copy of it, in the rehearsal.

## 2. Prerequisites

- A staging copy of the site that has never held and will never hold a production key, with its own database and a recent backup.
- Two throwaway keys and a third for the loss rehearsal, each a long random string, held only for this rehearsal. Their values are never written into this record.
- A second administrator account to act as the recovery authority, and the Publication Approver account used to export the audit trail.
