# Website Architecture & Technical Decisions

## Decisions

| # | Decision | Rationale |
|---|----------|-----------|
| 1 | Custom classic PHP WordPress theme (`noblen-corporate`) | Requested deliverable: installable theme, not static HTML |
| 2 | Custom post types for subsidiaries, industries, solutions, projects, partners | Editable by non-developers through the CMS |
| 3 | No page-builder or plugin dependency for core features | Maintainability and security |
| 4 | CI validates PHP syntax and WordPress coding standards | Keeps `main` stable |
